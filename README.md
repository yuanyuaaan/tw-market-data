# tw-market-data

台股追蹤清單（63 檔）與美股清單（16 檔）的每日技術面數據，由 GitHub Actions 自動計算。

- 來源：FinMind 日K（美股抓不到時改用 Yahoo）。
- 指標：MA5/10/20/60、RSI14（Wilder）、MACD(12,26,9) 柱、乖離月線、60 日新高新低、量比、趨勢分類。
- 價格斷層：台股單日漲跌超過 10% 漲跌停限制的，視為分割、減資或除權，往前還原後才計算。
- 廣度：最近 250 個交易日，每天只用當天以前的資料計算（不含 ETF/避險）。
- 輸出：`data/tw_latest.json`、`data/us_latest.json`。

排程（台北時間）：台股 15:40、16:40（週一到週五）；美股 06:10（週二到週六）。
清單在 `tech/watchlist.json`。這些是公開資料的整理，不是投資建議。
